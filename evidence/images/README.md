# Images

`before-stock.png` and `after-patched.png` are native 1920x1080 live in-game
screenshots from the Windows Dev Kit 2023. Both were recorded in a Dust II
offline practice deathmatch after spawn protection expired and with the same
CS2 video configuration. They are different viewpoints, not a pixel-matched
performance comparison.

Before recording each image, the mapped x86 Turnip provider was verified. The
stock image used SHA-256
`a0b6f67e7f7fb64f5418cca3a59c73f564ca6e0c24d175f7f346e3645f5959a0`;
the patched image used
`a9325e549221bad662895d97c60e9dffa39ec1a84ee09bd1882f0a7a17d79cce`.
